# Data-Cleaning-Project-Using-SQL
In this repository, we aim to clean our data, which is one of the most important steps in Data Analysis that helps us gain accurate and useful insights from our data. It's the second step we start after discovering our data.
In this project, we follow some steps so we can achieve the goals that we aim to achieve, which is preprocessing our data to start gaining insights from it :
First, we start by removing duplicates, which is one of the most important issues that we face in working on data. These issues affect our decision, so we are dealing with them by removing duplicates.
Second, we started to standardize our categorical data by putting it in the same format to gain valuable insights from it.
Third, we started working with null and blank values by removing them or by filling them with a responsible value to make our data ready and have valuable insights.
Fourth, we started removing the columns and rows that would not benefit us in gaining insights from the data.
